# rftinternship_day18
# Movie Dataset Analysis

## Project Overview
This project analyzes a movie dataset using Python.  
It performs trend analysis, correlation analysis, and data visualization on movie ratings, genres, and revenues.

The project helps in understanding:
- Highest rated movies
- Most profitable genres
- Rating distribution
- Correlation between ratings and revenue

# Features

## Highest Rated Movies
Sorts movies based on ratings.

## Most Profitable Genres
Calculates total revenue generated by each genre.

## Top 5 Movies
Displays top 5 highest-rated movies.

## Correlation Analysis
Finds relationship between movie ratings and revenue.

## Data Visualization
Creates:
- Genre vs Revenue Bar Graph
- Rating Distribution Histogram


# Visualizations

## 1. Genre vs Revenue
Shows which movie genre generates the highest revenue.

## 2. Rating Distribution
Shows how movie ratings are distributed.
